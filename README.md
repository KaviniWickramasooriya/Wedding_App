## 💍 About The Project

A gorgeous, highly responsive, and interactive digital wedding invitation web application built for **Anuthhara & Yasith**. Complete with custom 3D curtain opening animations, live countdown timers, Google Maps integration, an interactive photo gallery, and a fully functional guest RSVP system backed by Web3Forms.

---

## 🌟 Key Features

*   **🎭 Immersive Curtain Opening:** A physical accordion curtain transition effect on launch to set an elegant tone.
*   **⏳ Real-time Countdown:** Live ticking counter counting down to the big day on **December 2, 2026**.
*   **📸 Dynamic Photo Gallery:** Staggered entrance animations, zoom effects, and memory cards showcasing pre-shoot moments.
*   **📍 Location & Map Integration:** Direct Google Maps embed and quick "Get Directions" link for *Eagle Banquet Hall, Waters Edge, Battaramulla*.
*   **⏰ Schedule of Events:** Clean timeline cards highlighting the day's auspicious rituals, ceremony, and reception.
*   **💌 Interactive RSVP Form:** Fully integrated with Web3Forms so guests can instantly submit their attendance and guest counts.
*   **✨ Smooth Scroll Animations:** Powered by **Framer Motion** with re-triggerable `whileInView` scroll effects and hover interactions.

---

## 🛠️ Built With

*   **Frontend Framework:** React.js
*   **Styling:** Tailwind CSS
*   **Animations:** Framer Motion
*   **Icons:** React Icons (`Lucide` / `FontAwesome`)
*   **Form Backend:** Web3Forms API

## 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/your-username/wedding-invitation.git](https://github.com/your-username/wedding-invitation.git)

2. Navigate to the project directory:
   ```bash
   cd wedding-invitation

3. Install dependencies:
   ```bash
   npm install

4. Start the development server:
   ```bash
   npm run dev
